# query-response-file-management
A Java-based Query Response System for File Management using OOP concepts and file handling.

## 1. Project Overview

This system helps users register files, search metadata, record queries and manage responses efficiently.

## 2. Key Features

- File Registration
- Metadata Search
- Query Recording
- Response Management
- Record Display
- File-Based Data Storage

## 3. Technology Stack

- Java
- Java Swing (GUI)
- Java AWT
- Java I/O
- ArrayList and Collections
- Object-Oriented Programming
- VS Code
- GitHub

## 4. OOP Concepts

- Classes and Objects
- Encapsulation
- Constructors
- Methods
- Modularity

## 5. Data Storage

- `files.txt` – File metadata
- `queries.txt` – Query and response records

## 6. How to Run

Compile:

```bash
javac FileManagementSystem.java
```

Execute:

```bash
java FileManagementSystem
```

## 7. Future Enhancements

- GUI Integration
- MySQL Database
- User Authentication
- Advanced Search

## 8. Conclusion

The project provides an organized solution for file management and query tracking using Java and OOP concepts.
